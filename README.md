# Veri Yapıları ve Algoritmalar - Proje 1 (Enes Öztürk)

![Veri Yapıları ve Algoritmalar - Proje 1 (Enes Öztürk) — rozet](docs/rozet.svg)

> **Veri analizi · modelleme** — tasarım ve geliştirme: **Enes Öztürk**

---

Enes Öztürk imzalı Insertion Sort ve Selection Sort aşamaları, Big-O gösterimi, Time Complexity analizi ve interaktif algoritma görselleştirici.

## Öne çıkanlar

- Veri temizleme ve hazırlık
- İstatistiksel özet ve görselleştirme
- Modelleme ve tahmin adımları
- Yönetici özeti ve rapor görünümü

## Kurulum ve çalıştırma

```bash
npm install
npm run dev        # http://localhost:3000
```

| Komut | Not |
| --- | --- |
| `npm install` | bağımlılıklar |
| `npm run dev` | geliştirme sunucusu |
| `npm run build` | üretim derlemesi |
